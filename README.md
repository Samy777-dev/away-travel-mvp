# ✈️ Away Travel - Versão Inicial (MVP)

Este repositório contém a **primeira versão funcional** da Landing Page desenvolvida para a agência de viagens **Away Travel**. O objetivo principal deste projeto foi construir a estrutura de base (Mínimo Produto Viável - MVP) para apresentar os serviços de roteiros personalizados para destinos internacionais.

Este projeto foi fundamental para consolidar meus primeiros aprendizados práticos de estruturação, estilização e introdução à lógica de programação web, servindo como ponto de partida para a posterior refatoração premium do sistema.

---

## 🛠️ Tecnologias Aplicadas

- **HTML5:** Estruturação semântica da página e organização das seções de conteúdo.
- **CSS3:** Estilização básica, definição de cores, fontes e alinhamento dos elementos visuais.
- **JavaScript (Vanilla):** Implementação das primeiras interações dinâmicas e manipulação de elementos da interface.
- **Git & GitHub:** Utilizados para o controle de versão e publicação do portfólio.

---

## 📈 Aprendizado e Evolução Técnica

Desenvolver esta versão inicial foi um passo crucial na minha trajetória em **Engenharia de Software**. Ela me permitiu:
- Compreender a mecânica de alinhamento e fluxo de elementos em uma página web.
- Aplicar os primeiros conceitos de lógica de programação com JavaScript para criar dinamismo no site.
- Desenvolver a base conceitual necessária para, posteriormente, aplicar técnicas avançadas de refatoração, acessibilidade e conexões complexas de APIs na versão mais recente do projeto.
